# Primeiros passos

<Steps>

### Entre no painel da Beep

Acesse [app.beeptheme.com.br/login](https://app.beeptheme.com.br/login).

### Valide o token

Digite o token **`6B35FF`** no campo e clique em **Validar**. Assim que o token é aceito, você já entra no painel.

![Campo Insira o token abaixo, com o token 6B35FF e o botão Validar](/images/loja-integrada/evo/painel-token.webp)

### Ative os recursos que quiser

Todos os recursos do tema começam **desativados**. Para usar um recurso na sua loja, marque a opção **Ativar recurso** dele e preencha os campos como quiser.

![Caixa de seleção ativado, marcada](/images/loja-integrada/evo/painel-ativar-recurso.webp)

</Steps>

Algum recurso pede o link de uma imagem (ícones, banners do celular)? Veja [Imagens no gerenciador de arquivos](/loja-integrada/evo/imagens-no-gerenciador).

Terminou de configurar? Agora [leve o código para a loja](/loja-integrada/evo/salvar-o-codigo).

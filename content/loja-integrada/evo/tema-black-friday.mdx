# Tema Black Friday

O tema Black Friday é um visual para a época de Black Friday. Ele é instalado com um código colado no painel da Loja Integrada.

{/* TODO: confirmar se o código de Black Friday continua valendo. O manual é de 2022. */}

<Steps>

### Abra o Incluir código HTML

No painel da Loja Integrada, clique em **Personalize sua loja** e depois em **Incluir código HTML**. Clique no botão **Adicionar código**, do lado direito.

### Preencha os campos

| Campo | O que colocar |
| --- | --- |
| Descrição | `CSS - Black Friday` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | HTML |

![Campos do código CSS - Black Friday preenchidos](/images/loja-integrada/evo/black-friday-campos-codigo.webp)

### Cole o código

No campo **Conteúdo**, copie e cole o código abaixo:

```html
<link rel="stylesheet" href="https://cdn.awsli.com.br/2505/2505623/arquivos/style.css?v=0010" type="text/css">
```

### Salve e espere

Clique em **Salvar** e espere uns 20 minutos até a mudança aparecer na loja.

</Steps>

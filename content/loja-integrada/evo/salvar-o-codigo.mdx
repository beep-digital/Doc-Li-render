# Levar o código para a loja

Tudo o que você configura no painel da Beep vira um código. Esse código precisa ser colado no painel da Loja Integrada. Só assim aparece na loja.

<Steps>

### Copie o código completo

No topo do painel da Beep, clique em **Códigos gerados**. Na janela que abre, clique em **Código completo** para copiar.

![Janela com o card Código completo](/images/loja-integrada/evo/codigos-gerados-codigo-completo.webp)

<Callout type="info">
  Vai configurar mais coisas? Pode seguir configurando os outros recursos e copiar o código completo só no final.
</Callout>

### Abra o Incluir código HTML da Loja Integrada

No painel da Loja Integrada, clique em **Personalize sua loja** e depois em **Incluir código HTML**.

### Já existe um código chamado Plugins?

- **Sim:** clique nele. No campo **Conteúdo**, apague tudo o que está lá.
- **Não:** clique em **Adicionar código** e preencha os campos como abaixo.

| Campo | O que colocar |
| --- | --- |
| Descrição | `Plugins` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

![Campos Descrição Plugins, Local publicação Cabeçalho, Página publicação Todas as páginas e Tipo JavaScript](/images/loja-integrada/evo/incluir-codigo-html-plugins.webp)

### Cole e salve

No campo **Conteúdo**, cole o que você copiou do painel: aperte **Ctrl + V** ou clique com o botão direito do mouse e escolha **Colar**. Depois clique em **Salvar alterações**.

</Steps>

<Callout type="warning">
  A cada atualização, guarde uma cópia do código gerado num arquivo de texto no seu computador. É a sua cópia de segurança.
</Callout>

<Callout type="info">
  Trocou de navegador ou limpou o cache e o painel apareceu vazio? Dá para recuperar tudo com o botão **Revalidar código**. Veja [Perguntas frequentes](/loja-integrada/evo/perguntas-frequentes).
</Callout>

# Troca de cor

A troca de cor usa **dois códigos**. Instale os dois.

## Código 1

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Troca de cor 1` |
| Local publicação | Rodapé |
| Página publicação | Todas as páginas |
| Tipo | HTML |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/qBmYpKo?editors=1000](https://codepen.io/beepdigital/pen/qBmYpKo?editors=1000)

Este código não precisa de nenhuma mudança: só copie e cole.

### Salve

Clique em **Criar código**.


</Steps>

## Código 2

<Steps>

### Escolha a cor

Escolha a cor que você quer e anote o código dela em hexadecimal (por exemplo, `#14161A`). Uma tabela de cores ajuda: [tabela de cores HTML](https://celke.com.br/artigo/tabela-de-cores-html-nome-hexadecimal-rgb).

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Troca de cor 2` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JS |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/oNWdpWE?editors=0010](https://codepen.io/beepdigital/pen/oNWdpWE?editors=0010)

### Coloque a sua cor

No código, troque a cor pelo código hexadecimal que você anotou.

### Salve

Clique em **Criar código**.


</Steps>

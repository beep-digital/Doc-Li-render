# Funcionalidades

Cada funcionalidade do tema é instalada com um código no **Incluir código HTML** da Loja Integrada, ou com um ajuste no próprio painel da Loja Integrada. Antes de começar, veja [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo).

Instale só as que você quer usar.

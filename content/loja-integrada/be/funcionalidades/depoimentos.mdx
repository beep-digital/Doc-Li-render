# Depoimentos

Mostra depoimentos dos seus clientes, para outros clientes verem a boa experiência deles.

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Depoimentos dos clientes` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/dyWYVqw?editors=0010](https://codepen.io/beepdigital/pen/dyWYVqw?editors=0010)

### Preencha os depoimentos

No código, troque só o que está **dentro das aspas** (`' '`). Não apague as aspas nem o resto do código.

- **`$depoimentos_titulo`:** o título da seção.
- **`imagem`:** o link da foto do cliente. Suba a foto antes no **Gerenciador de arquivos** e copie o link.
- **`depoimento`:** o texto do depoimento.

![Código dos depoimentos com título, imagem e texto destacados](/images/loja-integrada/be/depoimentos-codigo.webp)

### Salve

Clique em **Criar código**.


</Steps>

<Callout type="info">
  Tamanho das fotos dos clientes: **100x100**.
</Callout>

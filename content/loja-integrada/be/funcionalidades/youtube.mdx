# Vídeo do YouTube

Mostra um vídeo institucional do YouTube na página inicial.

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Vídeo YouTube institucional - Página Home` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/ExmVwbb?editors=0010](https://codepen.io/beepdigital/pen/ExmVwbb?editors=0010)

### Coloque o link do vídeo

Copie o link do vídeo no YouTube e cole dentro das aspas.

![Código com o link do YouTube destacado](/images/loja-integrada/be/youtube-codigo.webp)

### Salve

Clique em **Criar código**.


</Steps>

# Tarja topo

Mostra mensagens para os seus clientes no topo da loja.

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Tarja topo` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/mdmJwbV?editors=0010](https://codepen.io/beepdigital/pen/mdmJwbV?editors=0010)

### Escreva as suas frases

Troque cada frase do exemplo pelo texto que você quer. No código, troque só o que está **dentro das aspas** (`' '`). Não apague as aspas nem o resto do código.

![Código da tarja topo com o texto de uma frase destacado](/images/loja-integrada/be/tarja-topo-codigo.webp)

### Salve

Clique em **Criar código**.


</Steps>

# Seletor de quantidade na vitrine

Deixa o cliente escolher a quantidade do produto direto na vitrine.

<Callout type="warning">
  Não funciona para produtos com variações.
</Callout>

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Seletor de quantidade na vitrine` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/LYyZerY?editors=0010](https://codepen.io/beepdigital/pen/LYyZerY?editors=0010)

### Ligue ou desligue

Deixe `true` para ligar. Para desligar, troque por `false`.

![Código com o valor true destacado](/images/loja-integrada/be/seletor-quantidade-codigo.webp)

### Salve

Clique em **Criar código**.


</Steps>

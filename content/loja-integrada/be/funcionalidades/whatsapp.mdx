# Botão do WhatsApp

Coloca um botão de atendimento pelo WhatsApp na loja.

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Botão do WhatsApp` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/eYWGdgb?editors=0010](https://codepen.io/beepdigital/pen/eYWGdgb?editors=0010)

### Coloque os seus dados

No código, troque só o que está **dentro das aspas** (`' '`). Não apague as aspas nem o resto do código.

### Salve

Clique em **Criar código**.


### Logo do WhatsApp (opcional)

Para mostrar o logo do WhatsApp do lado esquerdo do botão, copie também o código abaixo e cole em **Visual** > **Editar CSS**:

[https://codepen.io/beepdigital/pen/jOmoMBg](https://codepen.io/beepdigital/pen/jOmoMBg?editors=0100)

</Steps>

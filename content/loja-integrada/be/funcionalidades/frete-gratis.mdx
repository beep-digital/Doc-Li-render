# Alerta de frete grátis

Mostra ao cliente quanto falta para ganhar frete grátis.

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Alerta de frete grátis` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/ZEKbXZa?editors=0010](https://codepen.io/beepdigital/pen/ZEKbXZa?editors=0010)

### Coloque o valor

Dentro das aspas, coloque o valor que o cliente precisa alcançar para ter frete grátis.

![Código com o valor do frete grátis destacado](/images/loja-integrada/be/frete-gratis-codigo.webp)

### Salve

Clique em **Criar código**.


### Configure o frete grátis na Loja Integrada

O frete grátis de verdade é configurado no painel da Loja Integrada, em [Marketing > Frete grátis](https://app.lojaintegrada.com.br/painel/marketing/frete_gratis/editar). Use o mesmo valor do código.

![Tela de frete grátis da Loja Integrada, por região e por produto](/images/loja-integrada/be/frete-gratis-li.webp)

</Steps>

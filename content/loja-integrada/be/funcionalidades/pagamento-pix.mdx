# Selo de pagamento via PIX

Mostra o selo de pagamento via PIX. Use o código que combina com a forma de pagamento da sua loja.

O código muda conforme a forma de pagamento. Para **Boleto** e **Mercado Pago**, o código está nesta página. Para **PagSeguro**, use o link.

<Tabs items={['Boleto', 'Mercado Pago', 'PagSeguro']}>
  <Tabs.Tab>

```js
$(document).ready(function() {$('.parcelas-produto .accordion .accordion-group .accordion-heading img[alt="Boleto Bancário"]').after('<img src="https://cdn.awsli.com.br/910/910263/arquivos/logo-pix.svg" atl="selo pix">');$('.formas .accordion-heading .forma-conteiner.with-discount img[alt="Pague com Boleto Bancário"]').after('<img src="https://cdn.awsli.com.br/910/910263/arquivos/logo-pix.svg" style="width:65px;" atl="selo pix">');$('.gateways-rodape li img[alt="PagHiper"]').after('<img src="https://cdn.awsli.com.br/910/910263/arquivos/logo-pix.svg" style="width:65px;" atl="selo pix">');});
```

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Pagamento via PIX` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Cole o código da sua forma de pagamento

Copie o código da sua forma de pagamento, acima, e cole no campo **Conteúdo**. Não precisa mudar nada.

### Salve

Clique em **Criar código**.

</Steps>

# Limite de categorias no menu

Define quantas categorias aparecem no menu.

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Limite de categorias no menu` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Copie o código abaixo e cole no campo **Conteúdo**:

```js
$limiteCategoria = '6';
```

### Escolha a quantidade

Troque o número pela quantidade de categorias que você quer no menu. No código, troque só o que está **dentro das aspas** (`' '`). Não apague as aspas nem o resto do código.

![Código com o número de categorias destacado](/images/loja-integrada/be/limite-categorias-codigo.webp)

### Salve

Clique em **Criar código**.


</Steps>

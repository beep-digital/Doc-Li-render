# Botão sair da conta

Coloca um botão para o cliente sair da conta, na página **Minha conta**.

![Página Minha conta com o botão Sair da conta destacado](/images/loja-integrada/be/botao-sair-da-conta.webp)

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Sair da conta` |
| Local publicação | Rodapé |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/bGoEapK?editors=0010](https://codepen.io/beepdigital/pen/bGoEapK?editors=0010)

Este código não precisa de nenhuma mudança: só copie e cole.

### Salve

Clique em **Criar código**.


</Steps>

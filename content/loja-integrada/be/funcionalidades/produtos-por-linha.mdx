# Produtos por linha

Define quantos produtos aparecem em cada linha da vitrine, no computador e no celular.

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Quantidade de produtos por linha - Desktop` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/BaRzYQx?editors=0010](https://codepen.io/beepdigital/pen/BaRzYQx?editors=0010)

### Escolha as quantidades

No código, troque só o que está **dentro das aspas** (`' '`). Não apague as aspas nem o resto do código.

### Salve

Clique em **Criar código**.


</Steps>

# Botão Mega Promoções

Mostra um botão **Mega Promoções** no menu. Quando o cliente passa o mouse no botão, aparecem os produtos em oferta.

<Callout type="warning">
  Antes, no painel da Loja Integrada, coloque os produtos em oferta na categoria **Ofertas Especiais**. Coloque **pelo menos 4 produtos** nela.
</Callout>

![Lista de categorias com Ofertas Especiais destacada](/images/loja-integrada/be/mega-promocoes-categoria-ofertas.webp)

## No computador

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Botão Mega Promoções` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/yLbJvVr?editors=0010](https://codepen.io/beepdigital/pen/yLbJvVr?editors=0010)

### Salve

Clique em **Criar código**.


</Steps>

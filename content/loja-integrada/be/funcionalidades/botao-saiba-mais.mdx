# Botão Saiba mais

Coloca um botão **Saiba mais** no rodapé, para o cliente conhecer mais sobre a sua loja.

<Callout type="warning">
  O botão só aparece se a **descrição da loja** estiver preenchida. Veja [Descrição da loja no rodapé](/loja-integrada/be/funcionalidades/descricao-da-loja).
</Callout>

<Steps>

### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Botão SAIBA MAIS no Rodapé` |
| Local publicação | Cabeçalho |
| Página publicação | Todas as páginas |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/GRmpMOL?editors=0010](https://codepen.io/beepdigital/pen/GRmpMOL?editors=0010)

### Ajuste o botão

Para mudar o texto do botão, troque o que está dentro das aspas.

![Código com o texto Saiba Mais destacado](/images/loja-integrada/be/saiba-mais-codigo.webp)

### Salve

Clique em **Criar código**.


</Steps>

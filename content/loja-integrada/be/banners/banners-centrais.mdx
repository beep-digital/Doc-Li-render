# Banners centrais

Banners que aparecem entre as vitrines da página inicial. São dois grupos: abaixo da 1ª vitrine e abaixo da 2ª vitrine. As imagens ficam no Gerenciador de arquivos da Loja Integrada e os links vão no código.

## Abaixo da 1ª vitrine

<Steps>

### Suba a imagem

No painel da Loja Integrada, vá em **Configurações** > **Gerenciador de arquivos** e clique em **Enviar arquivo**.

![Gerenciador de arquivos com o botão Enviar arquivo](/images/loja-integrada/be/gerenciador-de-arquivos-enviar.webp)

### Copie o link da imagem

Copie o link que aparece embaixo do nome do arquivo.

![Link da imagem destacado no Gerenciador de arquivos](/images/loja-integrada/be/gerenciador-de-arquivos-copiar-link.webp)


### Crie um código novo

Siga [Como incluir um código](/loja-integrada/be/como-incluir-um-codigo) e preencha os campos assim:

| Campo | O que colocar |
| --- | --- |
| Descrição | `Banners centrais - Página Home - 1° Vitrine` |
| Local publicação | Cabeçalho |
| Página publicação | Página Inicial |
| Tipo | JavaScript |

### Copie o conteúdo

Abra o código no link abaixo, copie e cole no campo **Conteúdo**:

[https://codepen.io/beepdigital/pen/WNjQbeK?editors=0010](https://codepen.io/beepdigital/pen/WNjQbeK?editors=0010)

### Coloque os links das imagens

Cole o link de cada imagem dentro das aspas, no lugar do exemplo.

![Código dos banners centrais com os links das imagens destacados](/images/loja-integrada/be/banners-centrais-1-codigo.webp)

### Salve

Clique em **Criar código**.


</Steps>

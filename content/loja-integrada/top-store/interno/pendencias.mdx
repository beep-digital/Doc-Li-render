# Pendências do manual (interno)

Esta página não aparece no menu. É para a equipe Beep.

**Fonte:** `Manual - Instalação do Tema Beep - Top Store .docx` (Drive, pasta TEMAS - LOJA INTEGRADA > V4 - Top Store - LI > Manual, [link](https://drive.google.com/file/d/1EQyfoNSfgrEKsMGYmN-AMqzPy5S_3i7g/view)). Existe também um Google Docs com o mesmo nome em Documentos de Apoio ([link](https://docs.google.com/document/d/15Xvp2Fgh_qV3UCVtRKBS65AO-f9V3CNT5hPPhoNeXgg/edit)). Migrado para a central em 29/10/2026.

## Como foi migrado

O manual do Top Store é **quase idêntico** ao do Royal: mesmo painel (`painel.beeptheme.com.br`), mesmos componentes e funcionalidades, mesmo passo a passo de salvar. 80 dos 85 prints são o mesmo arquivo nos dois manuais. Por isso as páginas foram feitas a partir das páginas do Royal, conferidas contra o texto do manual do Top Store.

Diferenças do Top Store em relação ao Royal, já aplicadas:

- **Primeiros passos:** o tema a conectar é o **Top Store** (print próprio).
- **Depoimentos:** quatro cores (linha do título, fundo dos depoimentos, fundo dos itens de navegação, setas), em vez de só "cor de fundo dos cards". Print próprio do título.
- **Adicionar aos favoritos:** tem aba **Cores** (só a cor de fundo do botão). Sem print.
- **Tarja informativa:** print próprio, com o rótulo certo ("Item - 1"). O do Royal mostra "Depoimento - 1".
- **WhatsApp na vitrine:** o manual do Top Store não tem o print da configuração, só o do botão na loja.

## Para confirmar

As pendências do Royal valem também aqui, porque o texto é o mesmo. As principais:

| # | Página | Pendência |

| 1 | Introdução | O painel `painel.beeptheme.com.br` e o contato (atendimento@beepdigital.com.br, WhatsApp (11) 99317-6208) continuam valendo? |
| 2 | Componentes | A lista do painel mostra **Breadcrumbs** e **Informações adicionais**, que o manual não explica. |
| 3 | Tema | **Cor dos textos para a cor primária**: o manual diz só "cor principal de alguns textos". **Cor de texto para eventos de erro**: o manual repetiu a descrição do aviso de sucesso (erro de cópia). **Border radius**: o texto diz padrão 10, o print mostra 6. |

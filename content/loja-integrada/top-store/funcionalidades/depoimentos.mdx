# Depoimentos

Mostra depoimentos dos seus clientes na página inicial da loja.

![Exemplo da seção de depoimentos na página inicial](/images/loja-integrada/top-store/depoimentos-exemplo.webp)

## Cores

| Campo | O que muda |
| --- | --- |
| Cor da linha do título | Título do bloco de depoimentos |
| Cor de fundo dos depoimentos | Fundo de cada depoimento |
| Cor de fundo dos itens de navegação | Fundo das setas de navegação |
| Cor das setas de navegação | Cor das setas de navegação |

![Título do bloco de depoimentos destacado](/images/loja-integrada/top-store/depoimentos-cor-titulo.webp)

## Configurações

<Steps>

### Ative a funcionalidade

Ligue a opção **Funcionalidade ativa?**.

### Preencha cada depoimento

- **Imagem:** o link da imagem do depoimento.
- **Título:** sugerimos o nome do cliente.
- **Texto:** o depoimento, um texto curto.

As estrelas aparecem sozinhas.

![Campos de um depoimento](/images/loja-integrada/top-store/depoimentos-config.webp)

### Adicione ou remova depoimentos

Use os botões **+** e **-**.

</Steps>

<Callout type="info">
  Terminou? [Salve as configurações](/loja-integrada/top-store/salvar-as-configuracoes) para levar as mudanças para a loja.
</Callout>

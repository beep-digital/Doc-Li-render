# Tamanhos das imagens

Use estes tamanhos (largura x altura, em pixels) para as imagens ficarem certinhas na loja.

| Onde | Tamanho |
| --- | --- |
| [Full banner](/loja-integrada/royal/componentes/full-banner) | 1920 x 600 |
| [Mini banners](/loja-integrada/royal/componentes/mini-banners) | 416 x 400 |
| [Banner flex](/loja-integrada/royal/componentes/banner-flex) | 632 x 300 |
| [Banner single](/loja-integrada/royal/componentes/banner-single) | 1277 x 300 |
| [Carrossel de categorias](/loja-integrada/royal/funcionalidades/carrossel-de-categorias) | 130 x 130 |
| [Ícones da tarja informativa](/loja-integrada/royal/funcionalidades/tarja-informativa) | 40 x 40 |
| [Instagram](/loja-integrada/royal/funcionalidades/instagram) | 250 x 300 |

O tamanho do full banner no celular não está no gabarito do tema.

# Header

Aqui você muda as cores e alguns recursos do cabeçalho do site.

## Cores

| Campo | Onde aparece |
| --- | --- |
| Cor de fundo do header | Fundo do cabeçalho |
| Cor de fundo da tarja topo | Fundo da faixa acima do cabeçalho |
| Cor dos ícones do cabeçalho | Ícones do cabeçalho |
| Cor de fundo do menu | Fundo do menu principal |
| Cor de fundo do segundo nível do menu | Fundo do submenu |
| Cor de fundo do modal de conta | Fundo da janela de conta, no cabeçalho |
| Cor de fundo do modal de ofertas | Fundo da janela de ofertas, no menu |
| Cor de fundo do botão de ofertas | Fundo do botão de ofertas, no menu |
| Cor do texto do botão de ofertas | Texto do botão de ofertas, no menu |

## Configurações

### Limite de categorias

Quantas categorias aparecem no menu no computador. Basta digitar o número.

![Campo Limite de categorias do menu](/images/loja-integrada/royal/header-limite-categorias.webp)

## Tarja topo

Mostra uma frase importante, com um ícone opcional, no topo da loja. No primeiro campo vai a imagem do ícone. No segundo, a frase.

![Campos Ícone da tarja topo e Texto da tarja topo](/images/loja-integrada/royal/header-tarja-topo-config.webp)

## Modal de ofertas

<Callout type="warning">
  Antes, no painel da Loja Integrada, crie uma categoria chamada **Ofertas Especiais** e coloque nela os produtos em oferta.
</Callout>

Depois, no painel Beep Theme, preencha os campos do modal como quiser: título, subtítulo, texto do botão e número inicial do contador.

![Campos do modal de ofertas especiais](/images/loja-integrada/royal/header-modal-ofertas-config.webp)

<Callout type="info">
  Terminou? [Salve as configurações](/loja-integrada/royal/salvar-as-configuracoes) para levar as mudanças para a loja.
</Callout>

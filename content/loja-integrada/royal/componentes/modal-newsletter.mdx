# Modal newsletter

O modal newsletter é a janela que convida o cliente a se cadastrar para receber novidades.

<Callout type="warning">
  Para o modal aparecer, ele precisa estar **todo configurado e ativado no painel da Loja Integrada**. Siga o passo a passo da própria Loja Integrada: [Configurando o newsletter](https://ajuda.lojaintegrada.com.br/pt-BR/articles/931761-configurando-o-newsletter).
</Callout>

Depois disso, no painel Beep Theme você pode colocar uma imagem no modal. Basta colar o link da imagem no campo.

# Salvar as configurações

Tudo o que você configura no painel Beep Theme precisa ser levado para o painel da Loja Integrada. Só assim aparece na loja.

<Steps>

### Salve no painel Beep Theme

Depois de cada configuração, clique em **Salvar e enviar para o e-commerce**.

![Botão Salvar e enviar para o e-commerce](/images/loja-integrada/royal/salvar-botao-salvar-e-enviar.webp)

### Copie as configurações

Na janela que abre, clique em **Copiar configurações**.

![Janela com o botão Copiar configurações](/images/loja-integrada/royal/salvar-copiar-configuracoes.webp)

### Abra o Incluir código HTML da Loja Integrada

No painel da Loja Integrada, clique em **Personalize sua loja** e depois em **Incluir código HTML**.

![Menu Personalize sua loja, opção Incluir código HTML](/images/loja-integrada/royal/li-menu-incluir-codigo-html.webp)

### Adicione ou abra o código Plugins

- **Primeira vez configurando o tema:** clique em **Adicionar código**.
- **Já configurou antes:** procure o código chamado **Plugins** e abra ele.

![Tela Códigos HTML com o botão Adicionar código](/images/loja-integrada/royal/salvar-adicionar-codigo.webp)

### Preencha os campos

| Campo | O que colocar |
| --- | --- |
| Descrição | `Plugins` |
| Local de publicação | Cabeçalho |
| Página de publicação | Todas as páginas |
| Tipo | HTML |

![Campos do código Plugins preenchidos](/images/loja-integrada/royal/salvar-campos-codigo.webp)

### Cole e salve

No campo **Conteúdo**, cole o que você copiou do painel: aperte **Ctrl + V** ou clique com o botão direito e escolha **Colar**. Depois clique em **Salvar alterações**.

![Campo Conteúdo com o código colado e o botão Salvar alterações](/images/loja-integrada/royal/salvar-colar-conteudo.webp)

</Steps>

Depois de salvar, espere alguns minutos até as mudanças aparecerem na loja.

<Callout type="warning">
  **Toda** mudança feita no painel Beep Theme precisa deste passo a passo de novo. Se você mudou uma cor e não colou o código novo na Loja Integrada, a loja continua igual.
</Callout>

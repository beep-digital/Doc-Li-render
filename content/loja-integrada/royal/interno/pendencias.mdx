# Pendências do manual (interno)

Esta página não aparece no menu. É para a equipe Beep.

**Fonte:** `Manual - Instalação do Tema Beep - Royal` (Google Docs exportado em PDF, 43 páginas). Migrado para a central em 21/10/2026. O texto público segue o manual; o que estava confuso ficou escrito no mínimo e está listado aqui.

## Plataforma

O manual é da **Loja Integrada**: todos os passos usam o painel da LI (Personalize sua loja, Banners, Incluir código HTML, Páginas de conteúdo, Gerenciador de arquivos) e os links de ajuda são de `ajuda.lojaintegrada.com.br`. Os prints de exemplo são de lojas `*.lojaintegrada.com.br`.

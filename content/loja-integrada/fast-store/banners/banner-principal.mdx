# Banner principal (full banner)

**Onde aparece:** no topo da página inicial, logo abaixo do menu. É a primeira coisa que o cliente vê. Passa sozinho de tempos em tempos e aceita vários banners em rodízio.

| Item | Como cadastrar |
| --- | --- |
| **Posição no painel** | Fullbanner |
| **Nome** | Livre |
| **Imagem (computador)** | 1920 × 700 px |
| **Imagem (celular)** | 768 × 768 px — no campo de imagem para celular |
| **Quantidade** | Sem limite. Recomendamos de 3 a 5 |

## Passo a passo

1. Acesse **Banners** e adicione um novo banner.
2. Escolha a posição **Fullbanner**.
3. Dê qualquer nome (ex.: `Promo Outubro`).
4. Envie a imagem de computador (1920 × 700) e a de celular (768 × 768).
5. Preencha o link, se quiser que o banner leve a uma página.

<Callout type="info">
  Não precisa de palavra-chave: estar na posição Fullbanner já basta. A versão de celular vem junto no mesmo cadastro.
</Callout>

## Dicas

- Mais de 5 banners fazem o cliente esperar demais até ver o último.
- Deixe textos importantes longe das bordas: em telas diferentes a imagem pode ser levemente cortada.

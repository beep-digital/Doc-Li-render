# Como funcionam os banners

Os banners ficam em **Loja Integrada → Banners**. Cada cadastro tem três informações que importam para o tema:

| Campo do cadastro      | Para que o tema usa                                                    |
| ---------------------- | ---------------------------------------------------------------------- |
| **Posição**            | O grupo do painel (Fullbanner, Mini banner, Tarja, Vitrine)            |
| **Nome**               | A **palavra-chave** que define em qual espaço da loja o banner aparece |
| **Título do banner**   | O **texto que aparece na loja** (frases, nomes de categoria)           |

Além disso: a imagem de computador, a imagem de celular (quando o espaço usa) e o link.

## O nome decide onde o banner aparece

O painel tem poucas posições, e a loja usa mais espaços do que isso. Então alguns espaços **dividem a mesma posição** e o tema os separa pela palavra no nome.

Exemplo: três blocos diferentes usam a posição **Mini banner**. O que decide para qual deles o banner vai é o nome:

| Nome contém…     | Vai para…                                   |
| ---------------- | ------------------------------------------- |
| `Vitrine`        | [Dupla pós-vitrine](/loja-integrada/fast-store/banners/dupla-pos-vitrine) |
| `Central`        | [Banner central](/loja-integrada/fast-store/banners/banner-central)   |
| nenhuma das duas | [Trio de mini banners](/loja-integrada/fast-store/banners/mini-banners) |

<Callout type="warning">
  **Escreva a palavra-chave exatamente como indicado.** Uma letra a menos ou a mais e o banner aparece no lugar errado — ou some. Por isso o tema foi feito para que você **nunca precise mudar o nome** depois de cadastrado.
</Callout>

## Todo texto vai no título, nunca no nome

O nome é só a "etiqueta" que o tema lê. Qualquer texto que você quer mostrar ao cliente — "Frete grátis para todo o Brasil", "Óleos essenciais" — vai no campo **título do banner**.

Assim você pode trocar o texto quando quiser sem risco de quebrar o espaço.

## Imagem de computador e de celular

Os espaços que aceitam imagem de celular têm um campo próprio para ela no cadastro. O tema troca sozinho a imagem conforme o tamanho da tela — você só precisa cadastrar as duas.

# Vitrine destaque (slide)

**Onde aparece:** carrossel de banners antes do FAQ (ou antes do rodapé, se não houver FAQ).

![Exemplo de vitrine destaque em carrossel](/images/loja-integrada/fast-store/banners/vitrine-destaque.png)

| Item | Como cadastrar |
| --- | --- |
| **Posição no painel** | Vitrine |
| **Nome** | `Banner Vitrine` |
| **Imagem** | 632 × 672 px |
| **Quantidade** | No mínimo 3 |

## Passo a passo

1. Adicione um banner na posição **Vitrine**.
2. Nome: `Banner Vitrine`.
3. Envie a imagem e preencha o link.
4. Repita até ter pelo menos 3.

<Callout type="info">
  Mesma proporção da [Dupla pós-vitrine](/loja-integrada/fast-store/banners/dupla-pos-vitrine) (632 × 672, quase quadrada) — a mesma arte pode ser reaproveitada.
</Callout>

# Sobre esta documentação (interno)

Esta seção não aparece no menu. É para a equipe Beep.

## Como a documentação é feita

- Escrita em Markdown (MDX) na pasta `content/` e publicada com **Nextra**.
- Quem escreve é a IA (Claude Code), a partir das **fontes** em `fontes/` — transcrições de reunião e guias da equipe.
- O papel da equipe é **ditar o que o código não mostra**: como a Loja Integrada se comporta, tamanhos ideais de imagem, armadilhas do painel.

## Fluxo para atualizar

1. Abra o Claude Code na pasta do projeto.
2. Explique a mudança (pode ser por voz) ou cole a transcrição em `fontes/reunioes/`.
3. Peça para atualizar a documentação. O `CLAUDE.md` da raiz já dá o contexto do projeto para a IA.
4. Rode `npm run dev` e confira em `http://localhost:3000`.

## Público

Lojista leigo. Linguagem simples, sem termos técnicos, sempre com passo a passo.

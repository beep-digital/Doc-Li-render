# Depoimentos

Coloque até **8 depoimentos** de clientes. Eles passam em carrossel, no computador e no celular.

Para cada depoimento, preencha:

- **Título**: recomendamos o nome do cliente.
- **Texto**: um texto curto.
- **Foto**.

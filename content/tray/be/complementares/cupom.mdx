# Cupom

Mostre um cupom de desconto no menu da loja, com um botão para o cliente copiar o código.

## Como configurar

1. Na aba **Complementares**, abra **Cupom**.
2. Ligue **Exibir a aba de cupom?**.
3. Em **Insira o código do cupom**, escreva o código (por exemplo `BEEP10`).

![Configuração do cupom](/images/tray/be/cupom-config.webp)

<Callout type="warning">
  O painel da Beep só **mostra** o código. O cupom precisa existir na Tray, com o mesmo código, para o desconto funcionar. Veja [como criar um cupom na Tray](/tray/be/produtos-na-tray#cupom-de-desconto).
</Callout>

<Callout type="info">
  O cupom aparece **só no computador**. Você pode ligar e desligar quando quiser.
</Callout>

## Como aparece

A aba **Cupons Exclusivos** fica no fim do menu:

![Aba Cupons Exclusivos no menu](/images/tray/be/cupom-menu.webp)

Ao passar o mouse, aparece o código com o botão **Copiar**:

![Cupom com o botão Copiar](/images/tray/be/cupom-exemplo.webp)

# Documentação — tema Beep para o novo renderizador da Loja Integrada

Site de documentação feito com [Nextra](https://nextra.site).

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Atualizar o conteúdo

As páginas ficam em `content/` (MDX). O jeito recomendado é abrir o Claude Code nesta pasta e pedir a mudança — o `CLAUDE.md` já explica o projeto e as regras de escrita. Transcrições e materiais de referência vão em `fontes/`.

Pendências e decisões abertas: `content/interno/decisoes-e-pendencias.mdx` (acessível em `/interno/decisoes-e-pendencias`, fora do menu).
